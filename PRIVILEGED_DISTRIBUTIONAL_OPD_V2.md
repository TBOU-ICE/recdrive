# Privileged Distributional OPD v2

This directory is based on `recdrive-multi-opd-v1-gpt` and imports the teacher-training pieces from `recdrive-scene`.
All v1 files are kept; v2 is additive except for two backwards-compatible extensions to GoalBridge gating/logging.

## Recommended checkpoint lineage

Use one strong non-privileged deployable checkpoint as the common ancestor.

```text
strong non-privileged base
├── Student_init  (unchanged deployable branch)
└── privileged Teacher
    ├── goal-aware mixed IL
    └── goal-aware bucket RL  -> select BEST CLOSED-LOOP checkpoint
```

Do **not** select the teacher by final epoch or lowest train loss. Use the best closed-loop PDMS/bucket validation checkpoint. If your existing 93-94 PDMS goal teachers are better than newly trained ones, use those for the first v2 OPD ablation.

Recommended defaults:
- Teacher IL: full/bucket = 0.7/0.3, 8 epochs.
- Teacher RL: full/bucket = 0.3/0.7, 10 epochs. For very long-tail safety buckets, 0.2/0.8 is reasonable.
- Goal mode: `adaln` first, because the existing strong goal teachers and GoalBridge use it consistently.
- Student init: strongest deployable non-privileged checkpoint (prefer the previous ~89-PDMS student over a weaker IL-only base).

## Stage S1: Distributional OPD (Expand)

Run:

```bash
STUDENT_CKPT=/path/strong_deployable_student.ckpt \
TEACHER_PROGRESS_CKPT=/path/best_progress_goal_rl.ckpt \
TEACHER_RULE_CKPT=/path/best_rule_goal_rl.ckpt \
TEACHER_SAFETY_CKPT=/path/best_safety_goal_rl.ckpt \
TEACHER_GENERAL_CKPT=/path/best_general_goal_rl.ckpt \
SUPPORT_WEIGHT=0.25 \
SUPPORT_TEACHER_CANDIDATES=4 \
SUPPORT_STUDENT_CANDIDATES=4 \
RECOVERABILITY_FLOOR=0.25 \
ANCHOR_WEIGHT=0.05 \
ANCHOR_GATE_MODE=fixed \
bash scripts/training/run_recogdrive_train_distributional_goalbridge_opd_8gpu.sh
```

### v2 objective

```text
L = goal_w * L_goal
  + local_w * L_reverse_KL
  + support_w * L_support_JSD
  + anchor_w * L_anchor
  + smooth_w * L_jerk
```

- `L_reverse_KL`: original dense, per-DDIM-step local alignment. It teaches precise execution inside a mode.
- `L_support_JSD`: trajectory-support alignment. For every scene, K teacher candidates and K student candidates are sampled. Both policies score the same candidate chains using normalized diffusion-chain log likelihood. JSD aligns the categorical support distributions.
- `L_goal`: auxiliary intention bridge, not the primary knowledge target.
- `L_anchor`: fixed small trust region in v2. It is no longer amplified merely because goal prediction is poor.

### Why teacher + student candidates

Teacher-only candidates transfer good teacher modes but do not explicitly expose student-only bad modes. The shared set

```text
C(s) = teacher samples U student samples
```

lets the privileged teacher give low probability to bad modes currently generated by the student, while JSD remains mode-covering over multiple good modes.

### Recoverability change

v1 used low recoverability to simultaneously reduce KD and strengthen the anchor. v2 defaults are intentionally less conservative:
- `recoverability_floor=0.25`: difficult examples still receive a non-trivial local teacher signal.
- `anchor_gate_mode=fixed`: hard samples are not automatically pulled back to the old goal-free policy.
- support JSD is **not** multiplied by recoverability. Low goal recoverability means “do not force one exact local mode too strongly,” not “discard privileged support learning.”

For ablation, set `KD_GATE_MODE=none` to remove local recoverability gating entirely.

## Stage S2: OPD + GRPO (Joint / Sharpen)

Initialize from the **best S1 OPD checkpoint**, not from the original base.

```bash
STUDENT_CKPT=/path/best_distributional_opd.ckpt \
REFERENCE_POLICY_CKPT=/path/best_distributional_opd.ckpt \
METRIC_CACHE_PATH=/path/metric_cache_train \
OPD_WEIGHT=0.5 \
RL_WEIGHT=1.0 \
RL_SAMPLE_TIME=8 \
RL_BC_COEFF=0.05 \
bash scripts/training/run_recogdrive_train_distributional_goalbridge_joint_rl_8gpu.sh
```

Recommended schedule as separate resumable runs:

```text
Joint-1: OPD_WEIGHT=0.5, RL_WEIGHT=1.0
Joint-2: OPD_WEIGHT=0.2, RL_WEIGHT=1.0
Joint-3: OPD_WEIGHT=0.05, RL_WEIGHT=1.0
```

Do not start with strong OPD and strong RL from the first S1 step. First verify support expansion in S1, then let RL dominate progressively.

## Diagnostics to run before claiming success

The existing 87.7% train-cache deterministic recovery shows local imitation is already strong. v2 should therefore be judged on:

1. held-out deterministic recovery;
2. Student-visited / closed-loop-state recovery;
3. stochastic support metrics (teacher vs student diversity, minADE/coverage, energy distance or candidate JSD);
4. final closed-loop PDMS.

A useful success pattern is: deterministic recovery stays high, support JSD decreases, student diversity approaches teacher diversity without unsafe expansion, and PDMS closes the teacher/student gap after the joint RL stage.
